## 1. 价值主张

付费交付的是「个人命盘档案」，不是「API 字段导出」。验收：打开封面有身份感；八字页一眼等于站内盘；无半页空白公文感。

## 2. 页职（一页一职，填满再翻）

| 页 | 职 | 密度目标 |
|----|----|----------|
| 封面 | 品牌 + 姓名 + 生辰地 + 命局一行 + 纸纹/金线 | 上 2/5 有构图，非三行漂白 |
| 基础档案 | 口径条 + 三卡（格局/用神/命宫）+ 压缩摘要 + 双轨空态一行 | 上半满 |
| **八字满盘** | 六列：流年/大运/年/月/日/时；行：主星·干·支·藏干·星运·自坐·空亡·纳音·神煞（仅亮起） | **整页核心，日柱强调** |
| 大运时间轴 | 表 + 当前步标注 | 满表 |
| 紫微 | 命宫一句话 + 十二宫表 | 满 |
| 姓名 | 五格 + 用神交叉 | 有则满 |
| 可信度 | 三行人读置顶，细则收束 | 不抢戏 |
| 解读 | 分节短读 | 可跨页但不灌水 |
| 综合总结 | 3+1 | 可短但页底有边界条 |

禁止：空双轨独占页；空批注页；一句话占整页。

## 3. 视觉 token（打印）

- 纸色底 `#f5f0e6` / 表面 `#fffaf5`
- 墨 `#1a1410` · 金 `#b8894d` · 朱砂强调 `#8b3a2a`（少用）
- 标题宋体感（已有 PDF 字体栈）· 表体清晰
- 干支可用五行色（打印可辨即可，不发光）

## 4. 八字列数据源

- 四柱：`pillar_details`
- 当前大运：`dayun.items` 中含当前年者，或 `current_fortune_summary`
- 当前流年：`liunian.items` 对应当前年 / `liuri_liushi` 上下文
- 神煞：柱级 `shensha`，只印 `present`，不对全目录打灰

## 5. 验收

1. 封面无「漂字」感（有边框/金线/纸底）
2. 八字页含流年+大运列，且有空亡/星运/神煞亮项
3. 无「双轨对照附录」空页
4. 刘博回归脚本仍 pass
